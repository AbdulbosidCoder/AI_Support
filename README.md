# AI Support — Xonsaroy Pay

Бот поддержки клиентов Xonsaroy Pay. Сейчас работает в Telegram; логика ответов не зависит от канала,
поэтому позже её можно подключить к мобильному приложению.

Техническое задание: [docs/TZ.md](docs/TZ.md).

## Что умеет

- Отвечает по базе знаний (`data/knowledge_base/`) на узбекском (латиница и кириллица), русском и английском, на языке клиента.
- Понимает скриншоты приложения: определяет экран и ошибку, объясняет и даёт шаги решения.
  Вопрос может быть в подписи к фото или только на самом изображении (фото без подписи).
  Принимает фото, изображение файлом, альбом из нескольких фото (один ответ на всё) и вопрос
  текстом в ответ на свой ранее отправленный скриншот.
- Распознаёт голосовые сообщения через STT (Whisper-совместимый сервис).
- Маскирует номера карт, ПИНФЛ, телефоны и балансы и просит клиентов их не присылать.
- Передаёт обращение оператору: возвраты, отмены, разблокировка, лимиты, спорные операции, Antifraud, непонятные случаи.
- При первом /start здоровается на узбекском, русском и английском и просит выбрать язык
  (O'zbekcha, Ўзбекча, Русский, English; по умолчанию узбекский). Выбор сохраняется в базе.
- Меню с быстрыми вопросами (карта, SMS-код, платёж, перевод, квартирный долг, история),
  кнопками «Оператор» и «Настройки» (там смена языка). Быстрый вопрос отвечается так же, как
  набранный вручную: по базе знаний и через те же проверки запрещённых ответов.
- На приветствие («Salom», «Привет», «Hi», «нужна помощь») бот не перечисляет свои возможности,
  а коротко спрашивает, какая проблема, и показывает под сообщением мини-меню с готовыми вопросами.

## Пользователи и язык

Каждый клиент, написавший боту, сохраняется в SQLite (`DB_PATH`, по умолчанию `data/db/bot.sqlite3`,
в Docker это том `bot-data`): канал, id, chat id, username, имя, язык устройства и выбранный язык.
Выбранный язык нужен для меню и фиксированных ответов, а в v2 для уведомлений
(`UserStore.by_language`). Хранилище не зависит от Telegram, мобильное приложение будет писать
в ту же таблицу со своим `channel`.

## Жёсткие ограничения

Бот не принимает и не подтверждает финансовые решения, не называет статусы и сроки операций без backend
(в v1 backend не подключён), не раскрывает правила Antifraud. Это задано в промпте и дополнительно
проверяется кодом (`ai_support/guardrails.py`): запрещённый ответ модели заменяется безопасной передачей
оператору. Каждое изменение промпта или логики покрывается тестами в `tests/`.

## Устройство

```
ai_support/
  engine.py        ядро: сообщение клиента -> безопасный ответ (не зависит от канала)
  llm.py           Claude: текст и скриншоты, структурированный ответ
  prompt.py        системный промпт и схема ответа
  knowledge.py     загрузка базы знаний
  guardrails.py    запрещённые ответы и запросы, требующие человека
  pii.py           маскировка персональных данных
  language.py      определение языка
  stt.py           распознавание голоса
  templates.py     фиксированные ответы на 4 языках
  menu.py          быстрые вопросы, настройки, выбор языка (не зависит от канала)
  users.py         клиенты и выбранный язык (SQLite)
  channels/telegram_bot.py   адаптер Telegram и передача оператору
data/knowledge_base/
  screens.json     экраны приложения по скриншотам
  faq.json         темы поддержки (черновик, нужна проверка командой)
```

## Запуск через Docker Compose

```bash
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, SUPPORT_CHAT_ID, STT_API_KEY
docker compose up -d --build
docker compose logs -f bot
```

База знаний подключена как том только для чтения: после правки `data/knowledge_base/*.json`
достаточно `docker compose restart bot`, пересобирать образ не нужно.
Клиенты хранятся в томе `bot-data` и не теряются при пересборке и перезапуске.

## Запуск без Docker

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, SUPPORT_CHAT_ID, STT_API_KEY
set -a; . ./.env; set +a
python -m ai_support
```

Передача оператору: бот публикует обращение в чат `SUPPORT_CHAT_ID` (добавьте бота в группу поддержки).
Оператор отвечает реплаем на это сообщение, и бот пересылает ответ клиенту.

## Тесты

pip install -r requirements-dev.txt
